# Правила для ИИ-ассистента в этом репозитории

Проект: API платежей онлайн-школы (FastAPI + SQLAlchemy 2.0 + SQLite). Тестовое задание «Квитто».

## Команды
- Установка: `pip install -r requirements-dev.txt`
- Запуск: `uvicorn app.main:app --reload`
- Тесты: `pytest`
- Линтер: `ruff check .`

## Жёсткие правила
- Деньги — только `int` в копейках. Никакого `float`, никакого `/`: только `//`, `%`, `divmod`.
- Бизнес-правила (тарифы, промокоды, сроки рассрочки, таблица переходов статусов) живут
  только в `app/domain.py`. Роутеры тонкие, БД и транзакции — в `app/services.py`.
- Ошибка запрещённого перехода — ровно `409 {"error": "invalid_transition"}` (не HTTPException).
- Идемпотентность держится на UNIQUE-индексе `idempotency_key`, а не только на SELECT.
- Ошибки валидации — стандартный 422 FastAPI, свой формат не вводим.
- На каждое изменение логики — тест, который проверяет результат (состояние БД, значения),
  а не только код ответа.
- Новые зависимости не добавлять без необходимости.
- Перед завершением работы: `ruff check .` и `pytest` должны проходить.
